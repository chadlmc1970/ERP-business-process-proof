# ERP-business-process-proof

The Enterprise Process Conjecture: one business process, the three-way match in accounts payable, treated as a conjecture and attacked.

Start with [report/REPORT.md](report/REPORT.md) or the PDF beside it. Research lines are in `research/agents/`. Tests are in `research/tests/` and use the Python standard library only.

All simulation results are synthetic and illustrative. Legal and accounting readings have not been confirmed by counsel or an auditor.
